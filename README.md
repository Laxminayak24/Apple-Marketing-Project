# 🍎 Apple Social Media Marketing Analytics

## 📌 Project Overview

This project analyzes Apple's social media marketing performance across different platforms, campaigns, content types, and hashtags.

The objective is to evaluate social media engagement, campaign performance, audience reach, impressions, clicks, likes, shares, and comments to understand how different marketing activities perform.

The project uses data analytics and visualization techniques to transform social media data into meaningful business insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze social media performance across platforms
* Compare engagement across different social media channels
* Evaluate marketing campaign performance
* Analyze likes, shares, comments, clicks, reach, and impressions
* Identify frequently used and high-performing hashtags
* Compare campaign engagement before and during campaigns
* Understand audience interaction with Apple's content
* Create meaningful visualizations for marketing decision-making

## 📊 Dataset

The dataset contains social media marketing information with fields such as:

| Column      | Description                           |
| ----------- | ------------------------------------- |
| PostID      | Unique identifier for each post       |
| Platform    | Social media platform                 |
| Date        | Date of the post                      |
| ContentType | Type of social media content          |
| Hashtags    | Hashtags used in the post             |
| Likes       | Number of likes                       |
| Shares      | Number of shares                      |
| Comments    | Number of comments                    |
| Clicks      | Number of clicks                      |
| Reach       | Number of users reached               |
| Impressions | Number of times content was displayed |
| Campaign    | Associated marketing campaign         |

---

## 💡 Key Insights

The analysis identified several notable patterns:

* The **Apple Event Sept 2025** campaign recorded the highest engagement among the listed campaigns at **47%**.
* The **iPhone 16** campaign generated the highest impressions among the listed campaigns.
* **Twitter** recorded the highest engagement rate among the analyzed platforms.
* **LinkedIn** recorded the highest number of clicks among the analyzed platforms.
* `#AppleEvent` was the most frequently used hashtag in the analyzed dataset.
* Campaign-period engagement was compared with the pre-campaign period to understand changes in audience interaction.
